# プロモーションムービー風（promo）

西尾の語のまま（[[origin-2026-11-09]]）。三つの型の比較は [[three-video-types]]。ここは promo の作り方について、文献（`web-*`）と経験（`exp-*`）を並べる。

**文献の性格**: このページの文献はほぼすべてプラットフォームの広告販売の資料か、自社顧客データの業界調査。査読のある研究で無音自動再生・字幕・ループの効果を測ったものは、今回のサーベイでは見つからなかった（[[web-digiday-2016-85-percent-sound-off]] の担当の記録）。測っているのは主に広告の想起（ad recall）・ブランド指標で、西尾の動画の目的（最後まで見させる、講演の要点を渡す）とは測るものが違う。

## 文献が揃って言うこと

| 項目 | 文献の言い方 | 出典 |
|---|---|---|
| 最初の数秒 | Meta は Nielsen と組んで「価値の最大 47% が最初の 3 秒で届く」と書く（価値の定義は書かれていない）。TikTok は「3 秒で提案、6 秒以内にフック」。X は「商品は 3 秒以内、ブランドは 4 秒以内」。Google の ABCD は「5 秒以内にブランド」「最初の 5 秒に 2 コマ以上」 | [[web-meta-video-ads-best-practices]]、[[web-tiktok-creative-best-practices]]、[[web-x-video-ads-best-practices]]、[[web-google-youtube-abcds]] |
| 字幕・画面の文字 | どの面も勧める。ただし Meta の「視聴時間 12% 増」は社内テスト、Verizon Media・Publicis 2019 の「80% が字幕があれば最後まで見る」は自己申告。同じ調査は「字幕とロゴを同時に出すと広告の記憶が 12% 下がった」とも報告（二次情報） | [[web-digiday-2016-85-percent-sound-off]] |
| 縦長 | Meta 2017 は 4:5 か 9:16、Reels は 9:16 で下 35% を空けるセーフゾーン。TikTok は 9:16 | [[web-meta-video-ads-best-practices]]、[[web-tiktok-creative-best-practices]] |
| 尺（広告） | 6〜15 秒。Twitter の分析は Nielsen 調査 141 件・広告 1,617 本、Meta 2017 は「15 秒以下」、Google は 6 秒の bumper を分析 | [[web-x-video-ads-best-practices]]、[[web-meta-video-ads-best-practices]]、[[web-google-youtube-abcds]] |
| 尺（目的別） | Wistia は「認知を上げる・SNS で引き付ける」を 1 分未満に置く（Wistia 顧客の埋め込み動画の平均視聴割合。1 分未満の平均 52%） | [[web-wistia-video-length-engagement]] |
| 置き場所 | Yum Yum Videos（制作会社、宣伝目的の記事）は「置かれる場所が視聴者の意図を変える」「ブランド動画は機能の説明にほとんど時間を使わない」と書く | [[web-yum-yum-videos-explainer-script]] |

## 面ごとに違うこと: 音

| 面 | 公式の言い方 |
|---|---|
| X のタイムライン | 無音への備えを勧める（「A sound-off strategy」） |
| X の縦長全画面 | 音あり既定（字幕も勧める） |
| Facebook フィード | 2016 は無音前提 → 2017〜は「無音で通じ、音ありで良くなる」 |
| Instagram / Facebook Reels | 音あり前提（「over 75% … sound on」） |
| YouTube | 「almost entirely a sound-on experience」 |
| TikTok | 「it's a sound-on experience」。「120 BPM より速い曲で完了率が上がることが多い」 |

（[[web-digiday-2016-85-percent-sound-off]] の表を短くしたもの。各行の原典はそのページ）

「Facebook の動画の 85% は無音」は、パブリッシャー 2 社と代理店 1 社が Digiday の記者に語った 2016 年の自社の数字で、Facebook 全体の測定ではない、とそのページは書いている。

## 経験と並べる

- **一致**: X 用に「字幕だけで通じ、BGM は控えめ」にした（[[exp-democracy-river-video]]、[[exp-words-as-public-goods-video]]）のは、X のタイムラインについての X 自身の推奨と同じ向き。縦長 4:5 は Meta 2017 の推奨に当たる。50 秒でループする終わり方は X ヘルプの「60 秒以下は自動でループ」と噛み合う（[[web-x-video-ads-best-practices]]）
- **一致**: 最初のコマ・最初の 1〜2 秒が勝負（[[exp-shortmovie-draft-generator]]、[[exp-democracy-river-video]]）は、各社の「最初の 3 秒」と同じ向き
- **食い違い（目的の違い）**: 文献は「ブランドは早く出せ」。西尾は冒頭に問いを置き、答えや名前を最後に回収する構成をとった（[[exp-words-as-public-goods-video]]）。文献の測度は広告の想起で、西尾の目的は最後まで見させること
- **食い違い（面の違い）**: 同じ「字幕で通じさせ BGM は控えめ」の作りで YouTube にも上げているが、YouTube・TikTok・Reels の公式資料は音を主役にせよと言う
- **事実の更新**: [[exp-html-capture-pipeline]] の「縦長で 60 秒以内ならショート扱い」は、2024-10-15 以降 YouTube Shorts が「正方形か縦長で 3 分以内」になった（[[web-google-youtube-abcds]]）
- **要確認**: Gyazo の 47 秒版は 60fps（[[exp-gyazo-resumption-video]]）。X のヘルプはウェブからのアップロードを 40fps まで、と書く（[[web-x-video-ads-best-practices]]）。アプリからの場合や実際の挙動は確かめていない
- **要確認**: 西尾の動画は下端に進捗バーを置いている。Reels の「下 35% を空ける」、TikTok の UI と重なる位置
- 経験の「変化が止まるとテンションが下がる」（[[exp-sutra-hype-editions]]、[[exp-polis-magi-op]]）を直接測った文献は無い。TikTok の 120 BPM の記述は近いが、西尾の 120BPM は映像と音の時刻を合わせるための選択で、この数字を根拠にしたものではない

## Open Questions

- X の通常投稿でサムネイルを選べるか、公式資料で確かめられなかった（経験では最初のコマが使われる前提で焼き込んだ。[[exp-html-capture-pipeline]]）
- 「ブランドを早く」と「問いを冒頭に、答えを最後に」は、測るものが違う。西尾の目的（最後まで見られる・要点が残る）で測った資料は無い
- 音あり前提の面（YouTube Shorts・TikTok・Reels）に、無音前提で作った動画をそのまま出すことの損得は測っていない
