# Gyazo 配信再開の動画: galleria の構成案と Mac での作り直し（2026-09-29〜30）

題材は、Gyazo に保存していた約 13 万枚（API で取得した全件 127,913 件）を、公開済みの参照・投稿のまとまり・標本での試行・ローカル画像判定・本人のレビューで段階的に絞り、配信を再開した 2026 年 9 月の作業。galleria（RTX 5080 16GB）で Visual Jev 4B を動かし、10,082 枚 × 7 問を処理本体 43 分 24 秒（GPU 待ちを除く全体 約 44 分、1 枚の中央値 280 ms、PyTorch の peak 9.61 GiB）で判定した。（gyazo-delivery-resumption-retrospective.md）

## 1. galleria で作った構成案（2026-09-29、採られなかった）

所有者が構成を依頼し、galleria のエージェントが約 150 秒の案を作った。タイトル案は「13万枚の画像、公開して大丈夫？ ローカルAIで整理してみた」。

| 時間 | 内容 |
|---|---|
| 0–15 秒 | 配信再開の前に確かめたいが、画像は約 13 万枚ある（127,913 を大きく表示） |
| 15–40 秒 | 公開済みを除き、標本確認と投稿構造から一括投稿群を分け、個別分析の対象を約 1 万枚に絞る |
| 40–70 秒 | Visual Jev 4B は何をする AI か（質問と選択肢、共通計算の再利用） |
| 70–90 秒 | 残った 10,085 件から 1,000 件を無作為に抜いて試す |
| 90–110 秒 | 10,082 件全体へ。GPU 待ちを除き約 44 分、VRAM peak 約 9.6 GiB |
| 110–135 秒 | 本人の基準を反映し、危険順・大きな画像・非公開ボタンで確認する |
| 135–150 秒 | 非公開判断 49 枚、本人が配信再開 |

時間は編集上の割り当てで、読み上げを計った値ではない。

### 構成案の段階で西尾が直したこと

- **標本で試す工程の省略を指摘した。** 初稿の「残り約 1 万枚をすぐ全件分析」は省略が大きく、1,000 枚で試してから約 1 万枚へ広げた段階を残すよう直された。
- **Visual Jev 4B の説明を入れるよう指定した。** 案の説明文: 「使ったのは、Visual Jev 4B。画像を見て、『認証情報が写っている？』『私信の画面？』といった質問に、選択肢ごとのスコアを返すAIです。…今回はこれを、自分のPCで動かしました。」字幕は「Qwen3-VLベース／4B＝約40億パラメータ／ローカル実行」。

### 構成案が守ろうとした事実関係（数字の言い方の注意）

- 49 枚は非公開と判断した数で、モデルの正解数ではない。
- 約 44 分は画像の取得や人のレビューを含まない。待ち込みの総経過は 2 時間 22 分 30 秒で、そのうち 1 時間 38 分 31 秒は GPU の空き待ち。
- 公式の按分値 5.7 ms/問を今回の画像 1 枚の速度として紹介しない。
- 一括投稿候補 104,081 件を全部「書籍」「公開可」と言い切らない。「91.2% は一括投稿候補の割合」であって確定率ではない。
- 一括投稿群の発見を、最初から自明だったように説明しない。

## 2. その後: 西尾の「適切とは思わない」と Mac での作り直し（2026-09-30）

所有者は約 2 分半の案を「適切とは思わない」とし、Mac のセッションで作り直した（2 分 52 秒 → 1 分 55 秒 → 47 秒、60fps・120BPM、冒頭 2 秒が X 用サムネイル）。作り直しの方針と西尾の発言は [[exp-gyazo-resumption-video]] に Mac の repo から書かれているので、ここでは繰り返さない。galleria-wiki の記録にある方針の見出しだけ挙げると: 主役は Visual Jev 4B でモデル名を出す／テンポ／気づきと実測を両方残す／比較は実務の代わりになるものと同条件で（同じ Qwen3-VL-4B に 7 問を JSON で答えさせると中央値 1.57 秒/枚、Visual Jev 4B は 0.28 秒/枚、約 5.6 倍。galleria が測った）／説明なしで伝わる言い方に／結末は所有者の言い方で。

## 構成案と完成版の差から言えること

- galleria 側の構成案は、事実関係の正確さ（数字の条件、工程の省略の禁止）にはよく気を配っていたが、尺・テンポ・主役の選び方で採られなかった。Mac 側の README は、v1 で「作業の順に数字を並べる『作業報告』」をやめたと書いている（[[exp-gyazo-resumption-video]]）。
- 構成案で守ろうとした条件（44 分は取得と GPU 待ちを除く、5.6 倍は速度だけ、など）は、完成版では画面から外れ、YouTube の説明文に実測ごとの条件として書かれた（`youtube/UPLOAD.md`、galleria-wiki の raw 2026-09-30-gyazo-video-youtube-description.md）。**正確さの注意は概要欄へ、画面は短く強く**という分け方になった。
- 「安全の証明ではない」という注記は所有者が不要とした。構成案が入れたがった但し書きのすべてが視聴者に要るわけではない。
- 作業の現場（galleria）と動画の制作（Mac）が別の機械になった。実測と事実関係は galleria-wiki、映像の部品は Mac の repo にある。動画のために追加の実測が要ったとき（JSON 生成との比較）は、Mac から galleria の Claude へ依頼して測ってもらった（同ページ）。
