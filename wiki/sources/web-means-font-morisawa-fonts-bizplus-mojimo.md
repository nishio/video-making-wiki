# 商用フォント（モリサワ・mojimo）と OS 付属フォントの動画での扱い

## 何の文献か

フォント事業者の公式ページ（商業利用の説明、価格、FAQ、使用許諾・利用規約）と、Microsoft の「Font redistribution FAQ for Windows」、Apple の macOS Tahoe の使用許諾（PDF）。事業者自身の解釈で、契約の本文（EULA）を全部読んだのは BIZ+ だけ。

## 書いてあること

### モリサワ（MORISAWA PASSPORT → Morisawa Fonts）

- MORISAWA PASSPORT は新規契約を 2023 年 3 月末の見積で終え、Morisawa Fonts へ移行（passport のページ）。順次終了と書く
- Morisawa Fonts のデスクトッププラン（税込、1 ライセンス・1 年）: Select8 26,400 円（8 書体）、Select24 43,560 円（24 書体）、スタンダード 64,240 円（3,500 書体以上）。いずれも「商業利用、商標登録OK」「PC2台まで利用可能」（同時起動は不可）。フリープランは「厳選した5書体」（plans のページ）
- 「商業利用について」のページ: 商業利用例に「テレビなどでのテロップ・フリップ表示(映像などの表示も含む)」「インターネットでの表示および頒布」。Q.1 は「作品名、人名、地名を表すタイトル、テロップ、クレジットなどの画像データを作成し、それらを映像に合成して、映像作品を制作し、上映、放送またはWEBサイトへ掲載して送信すること」を許諾の範囲と答える。Q.2 は成果物を「期間・地域・回数・使用方法・使用媒体など ... 何らの制限を受けることなく」利用できると答える。ゲーム・機器に「フォントの代替として機能するような画像・アウトラインなどのデータ」を載せるのは許諾外
- Morisawa Fonts の EULA 本文は読んでいない（ページはリンクのみ）

### MORISAWA BIZ+（ビジネス用 UD フォント）

- 価格: 全 68 書体で 1 ヶ月 330 円、1 年 3,960 円（税込）。無償版は BIZ UD ゴシック／明朝の 3 書体（bizplus の価格ページ）
- 利用規約（2023-06-01 から適用）: 作成した電子文書・出力物を「有償・無償を問わず、（Ａ）印刷物、（Ｂ）映画、テレビ番組、ビデオ、DVD、ゲームソフト等のタイトル・テロップ・フリップ、（Ｃ）ウェブサイトのバナー広告 ... として利用することができます」
- 禁止事項に「本フォントをネットワーク上のサーバとして機能するデバイスにインストールし、クライアントとして接続する他のデバイスからアクセスして使用すること」「本フォントにあらかじめ設定された技術的な制限を解除、無効化する行為」「本フォントを使用して作成したロゴを商標登録または意匠登録すること」
- インストールは専用のデスクトップマネージャーで、オンライン認証のあるデバイスに限る

### Fontworks: mojimo-EVA（マティス-EB）

- 「エヴァンゲリオン公式フォント マティスEB TrueType版」（2016）は「販売終了。今後の再販予定はございません」（fontworks.co.jp）
- 現行は mojimo-EVA: 「EVA-マティス-クラシック」（TV シリーズ）と「EVA-マティス-スタンダード」（新劇場版）、「年間定額制の999円」「1PC / 個人契約のみ」「法人でのご契約は出来ない」（mojimo.jp/eva）
- 使用許諾（mojimo.jp/license/eva）: 「YouTubeなどの動画共有サービスでのご利用が可能な製品となっており、ゲーム・アプリ・放送用の映像・組み込み・サーバー利用・Webフォントでのご利用に関しては、使用許諾外」。表で「動画共有サービス ○」「Webフォントとして使用 ×」
- FAQ: 動画共有サービスでの使用は「ご契約者ご本人様の作品をご本人の動画共有サービスで配信する使用に限り」。mojimo-EVA は「動画の収益化（広告収入の発生）が可能なパック」。「スーパーチャット（投げ銭）等の動画共有サービスの広告収入以外で映像や動画等に対し対価が発生する場合は、ご利用いただけません」。第三者から依頼された動画は許諾外で、LETS の契約が要る

### OS 付属のフォント

- Microsoft（Font redistribution FAQ for Windows）: 「Can I use the fonts to produce captions and text included in videos?」→「We view this as the same as graphic files, providing the captions or text is rendered as a bitmap image, and the font files themselves are not embedded within the video file」。ただし「home, student, or non-commercial use」に限られたアプリで作った場合を除く。Windows のフォントを Web サーバーに置く（self-hosting）権利は無い
- Apple（macOS Tahoe の使用許諾 2.E）: 「you may use the fonts included with the Apple Software to display and print content while running the Apple Software; however, you may only embed fonts in content if that is permitted by the embedding restrictions」。動画への焼き込みを名指しした記述は無い

## この wiki への含意

- **アニメ OP 様式の明朝**: [[exp-polis-magi-op]] が借りた様式の元の書体はマティス-EB（Fontworks が「エヴァンゲリオン公式フォント」と書く）。正規に使う道は mojimo-EVA（999 円/年）だが、**個人契約・本人のチャンネル・広告収入までに限られ、会社の発信物や依頼された動画には使えない**。加えて「Webフォントとして使用 ×」で、HTML で描いて headless Chrome で撮る流れ（[[exp-html-capture-pipeline]]）が `@font-face` でファイルを読むと、この「Webフォント」に当たるかが条文から決まらない。OS にインストールしてフォント名で指定する形なら当たらない、と読める（推測）。様式を借りること自体の問題は rights の担当の範囲
- OFL の Noto Serif CJK JP Black・Zen Old Mincho Black（[[web-means-font-sil-ofl-noto-zen-mincho]]）は、こうした契約の条件が無い代わりに、マティスの字形ではない
- **Linux で描く流れと商用フォント**: Morisawa Fonts・BIZ+・mojimo は Windows / macOS のアプリでインストールし、オンライン認証で管理する。WSL や CyEC2 の headless Chrome から使うには、フォントのファイルを Linux 側へ写す必要があり、BIZ+ の規約の「技術的な制限を解除」「サーバとして機能するデバイスにインストール」の禁止に触れうる。**商用フォントで描くなら Windows 側の Chrome か Mac で撮る**のが条文に沿う（推測）
- BIZ UD ゴシック／明朝は Google Fonts に OFL 版（BIZ UDPGothic・BIZ UDPMincho）があるので、Linux ではそちらを使えばよい
- Windows 付属フォント（游明朝など）は、galleria の Windows 側で描いて焼き込むなら Microsoft の FAQ の範囲。WSL の Linux から `/mnt/c/Windows/Fonts` を読ませる使い方は FAQ の想定（Windows のアプリ）の外で、未確認
- Mac のヒラギノで描いた既存の動画（[[exp-html-capture-pipeline]]、[[exp-sutra-hype-editions]]）は、Apple の許諾の「display ... while running the Apple Software」で描いた画面を動画にしたもの。動画を名指しした許諾の文は無いが、禁止の文も無い

## 着手の仕方（未検証。galleria で確かめる）

- **何が表現できるようになるか**: 商用の書体（リュウミン・新ゴ・UD 書体、マティス-EB）でテロップ・タイトルを作る。効く型: promo（書体の個性）、talk（UD 書体）
- **機械**: galleria Windows または Mac（フォントの管理アプリが Windows / macOS 用）。Linux（WSL・CyEC2）では使わない
- **費用・アカウント**: 要: アカウント・費用。Morisawa Fonts Select8 26,400 円/年、BIZ+ 3,960 円/年、mojimo-EVA 999 円/年（個人契約のみ・会社の動画は不可）。どれにするかは西尾が決める
- **最小の手順**: 契約後、Windows 側でフォント管理アプリからインストール → Windows 側の Chrome（または PowerPoint・Premiere）でタイトルを描き、PNG に書き出して WSL の ffmpeg で合成する（推測。描く所だけ Windows に置く）
- **動いたと言える確かめ方**: Windows 側で書き出した PNG にフォントが当たっている（字形を見本と目で比べる。Chrome なら DevTools の「Rendered Fonts」にフォント名が出る）
- **所要の見込み（推測）**: 契約後 1 時間

## Open Questions

- Morisawa Fonts の EULA の本文（Linux での使用、仮想環境、ヘッドレスのブラウザ）を読んでいない
- mojimo の「Webフォントとして使用」が、ローカルの HTML を headless Chrome で撮る時の `@font-face` を含むか。問い合わせ先は Fontworks
- Apple の許諾の「display and print content」が動画の書き出しを含むか。条文には動画の明示が無い
- 会社の発信物に商用フォントを使う場合、契約者（会社か個人か）を誰にするかは西尾が決める
