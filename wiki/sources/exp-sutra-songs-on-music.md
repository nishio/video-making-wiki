## 割り付けの原則（曲の刻みと意味の刻みを合わせる）

西尾は残テを「曲の刻みと意味の刻みが尊重され、経文の重要ではない部分は割愛された」と評価し、これを他の曲へ広げたいとした（既存曲に般若心経を載せる制作ノウハウ 2026-10-11）。

- 全文を音符へ順に詰める前に、**曲のフレーズと聴かせたい経文の塊を対応させる**。全体（見せ場）→フレーズ（休符・終止・弱起）→音符（モーラ・子音）の順に考え、音符で窮屈なら上へ戻る
- 意味の区切りは旋律の小区切り（休符、なければ小節線か小節の真ん中）に合わせる。「不生不滅 / 不垢不浄」。弱起のサビでは原曲の句の切れ目が拍2にあった。「句境界を尊重する」と「全部を小節頭に押し込む」は違う
- **意味の軽い語は省いてよい**が、省いた字は原文から消さず `{舎利子}` のように印を残し、つなぐと原文に戻ることを検査する。省いた語を男声の掛け声で補う案は本人が「単純に不要」とした
- 詰まる所は2字で1音を分け合う。どこを詰めるかは人が決める
- 音の細かい罠（1音1モーラ、伸ばし音を言い直さない、短い音の次の子音が潰れる、高い音に開いた1音節）は[[exp-sutra-voicevox-singing]]
- サビを繰り返す継ぎ目は詰める。TV サイズはサビ1で終わる作りなので、そのまま繰り返すと約2秒あく。最後の音を伸ばすのも空けるのも西尾「へん」。伴奏を1小節手前で戻すと約0.2秒に詰まった
- **全曲より有名な一節のショートを先に作る**（西尾「とりあえず全体ではなくメジャーなフレーズに般若心経を載せるショート動画を作ろう」、2026-10-11）

## カノンで西尾のレビューから変えたこと

般若心経のカノンの制作「本人レビューで変えたこと」と 2026-10-06〜07 Updates より。

1. **リズムが一定すぎて退屈** → 西尾「状況によりモーラを伸ばしてもいい」。句末・呼びかけは伸ばし、列挙は詰めた編曲リズムを作った
2. **終わり方** → 本人案の「3人→2人→1人と減って最後に合唱で般若心経」
3. **題名は唱えない** → 第1声が本文から入る方が、2声目が「追いかけてきた」ことがすぐ分かる
4. **1和音に1語**。語が音の切れ目をまたいで「にゃ」がずり落ちると納得感がない
5. **画面は関係が見えることが要**。最初は3声を3本の横帯に分けたら、西尾「3本個別だと関係性がよくわからない、どれが和音になっているのかもわからない」。1枚の共通ピアノロールに3声を色違いで重ね、背景に和音の列を流した
6. v2 の改稿（西尾「本気で人間が歌えるもの、歌って気持ちいいもの」）:
   - 先に重要フレーズを決め、それ以外は声を張らない「あいだ」にする（西尾の進め方）
   - 強調を3声で重ならずに受け渡す設計を全編に当てたら、西尾「いいチャレンジだったが、休符がたくさんあるのはイマイチ」。各声の休みが 11%→21% に増えていた
   - 西尾「このギャップを埋めたら しきふいく と しきそくぜく がハーモニーになっていいのでは」→ 句を隙間なく並べると2句ずつ重なって同じ字がそろう。**リレーより、同じ字がそろって鳴る方が気持ちいい**
   - 「無が重ならない3拍周期」は本人が「間違いだった」。3拍の塊が4拍子を流れて強拍を見失う。**自然に歌って気持ちいいのがいい**＝句ごとに自然な長さ、無は強拍、1拍1語
   - 音量の操作は全面廃止（本人）。目立たせ方を「声がそろうこと」に置き換えた
   - 本人が大事とした v1→v2 の差分5点（そろいの数 15→49、無を強拍に、般若波羅蜜多を2小節目の頭に、1拍1語、音量をやめてそろいで目立たせる）を、概要欄・記事の説明の軸にした
7. v2 の画面（西尾「異なるパートでタイミングがそろうところが増えたので、それがカッコよく心地よく見えるように」「ピアノロールは情報量が少ないから圧縮しても良い、消してすら良い」）:
   - 字を唱え始める拍の x に置く。同じ瞬間に唱える字は縦一列に並び、カノンのずれと2句重ねが列として見える
   - 同じ字が同じ拍にそろう所を金の縦線で結び、再生位置で光らせる。字ごとにそろい続ける所（咒）は1拍に1度だけ光らせる（全部光らせると画面が埋まった）
   - **そろいの予告**（西尾「光る前の流れてくる段階でもイベントの予告があると良さそう」）: 16分10個前から外から輪が縮んできて、当たる瞬間に重なって光る（音ゲーの型）
   - **字の意味に動きを当てる**（西尾）: 無・不・空＝唱えた瞬間に「なくなる」、咒＝力を放つ放射。放射を細い線で描いたら照準に見えたので楔形に

## 替え歌（残テ）の演出で決まったこと

残酷な般若心経のテーゼの制作より。

- **替え歌は今歌っている漢字が読めないと面白くない**。面白さは「あの旋律に般若心経が乗っている」と分かる瞬間にある。エヴァ OP の文法（字は少なく一瞬、謎めかせる）はそのまま使うと逆効果
- A 区間20秒を3案で書き出して比べ（①1語のカードが主役・歌詞は帯、②歌詞を中央に大きく・カードは差し込み、③縦書き）、西尾「a-2がすき」で②に決まった
- 演出は歌詞の上と後ろの層に載せる。**経文にある数を元ネタの画の同じ数に当てる**（十二因縁→12枚の翼、三世諸仏→3枚の盤）。数が合わないもの（生命の樹＝10）は当てない。それがこじつけに見えない条件、という設計判断
- 西尾の評価「かっこよさが足りない」（2026-10-01）を受けて galleria へ移し（最初の手がかりは同じ機体のエヴァ OP 様式の制作 [[exp-polis-magi-op]] で効いた「カットを原作並みに速く」）、そこで一日に十数版重ねた（冒頭の無音が長く退屈→4.3秒詰める、「亦が大きく扱われて違和感」→つなぎは小さく、「五蘊以外の分類名も出し、乃至で飛ばすものもざっと流してよい」→分類名を追加、冒頭タイトル1コマ→「ないほうがよかった」で撤回、など。zankoku-hannya/HANDOFF.md）
- 初稿では見出しは五蘊だけ（アゲアゲ版で「見出しが多いとごちゃつく」と分かったため）だったが、後の本人要望で六根・十八界・十二因縁・四諦の分類名も出した。**同じ作り手でも作品が違えば逆の判断になる**例

## フィードバックの道具（効いた順）

残酷な般若心経のテーゼの割り付け「フィードバックの道具」、般若心経のカノンの制作 2026-10-07 より。

- **「1行聞く→ここが変と言う」に道具を合わせる**。最初の試聴ページ（字をクリックして場所を指し、コメントを書く）は「聞きやすいがフィードバックしにくい」。「場所を言葉で指すのが面倒」だった。字をクリックするとその行の終わりまで再生して止まり、コメントは今聞いた行に自動で付き、送ると次の行へ進む形にした。1周約5分で13件のコメントが一気に出た（`zankoku-hannya/player.html`、`serve.py` が `feedback.jsonl` に追記）
- **聴き比べは前後の行込み**。行だけを切り出すと「聞きづらい」
- **言葉にできない違和感は原曲の参照と図で見える化する**。原曲の歌詞を同じ旋律・同じ声で歌わせた版を並べ、拍・小節線・楽譜の音・実際の f0・音素区間・再生位置を1枚に描く
- カノンでは1声ずつ書き出して「1声で自然か」を聴くページ（`canon_solo_page.py`）。行番号と拍で指してもらう
- galleria の Codex は、版ごとにレビューページを作り、修正箇所の時刻へ飛ぶボタン（「00:51 亦・乃至のつなぎ」）と、前の版の同じ時刻と比べるボタンを付けた
- 技術メモ: Python 標準の `http.server` は Range 要求に対応しないので、ブラウザが音声の途中へ飛べない。自前で 206 を返す。VS Code が localhost のポートを先に握ることがあるので空きポートを OS に選ばせる

## 全編の検査の型

西尾「きちんと全編をチェックして」。指摘を1つずつ受けて直すと漏れが続いたので、型を作った（般若心経のカノンの制作 2026-10-07）。

1. 2秒ごとのコマを 4×4 に並べた一覧で全体の見え方を見る
2. 動きを付けた字（空・無・不・咒＝129回）を1回ずつ、唱えた瞬間・16分3個後・10個後の3コマで切り出して並べ、全部が「光る→抜け殻／放射→消え残る」になっているかを見る

これで「以無所得」の無だけ小さく（39px）動きが見えないのが見つかり、動きを付けた字は最小 52px にした。

galleria の残テの改稿では、毎版で「全編デコード、入力ハッシュ、修正範囲外の N 時点が前の版と一致」を確かめてから渡していた（HANDOFF.md）。

## 詰まったこと・事故

- **並行で動く割り付けに演出を秒で結ぶとずれる**。行の名前と字（「明」「乃至」「老」「尽」の位置）から毎回 `notes.json` を読んで時刻を引く。描画中に別 session が `notes.json` と音声を作り直したことがあり、描画の前後で入力の更新時刻（ハッシュ）が変わっていないか確かめる
- **長い動画は画だけ先に書く**。カノンの画は編曲・旋律の正本だけで決まり音声に依存しないので、固まった前半0〜92秒を音声なしで先に書き出し、改稿中の後半だけ書き直して `-c copy` で連結した。区切りは「改稿中の行が画面右端（再生位置の50拍先）に入る時刻」より前（西尾「前半部ができてると全体のレンダリングが楽かなという意図」）
- **作り直しの前の `git checkout` で未コミットの版を消した**。以後、本人の直しは1つずつ wip コミットした
- **文字画像を字形の外接枠で切ると、「一」のような横長の字が行の上に浮く**。縦はフォントのアセント・ディセントで揃える
- 字を光らせるタイミングは字ごとの読みで決める（比例配分だと「五蘊」の蘊が「ん」に来る）
- 極太明朝が Mac に無かった（ヒラギノ明朝は W6 まで）。Noto Serif CJK JP Black（OFL）を入れ、使う字が全部 cmap にあることを先に照合した
- **人間が一緒に歌う版は「飽きた」で中断**。お手本の声と一緒に歌うページを作ったら西尾「全然歌えない、まずは1声で一緒にミラーリングしないと」「この画面では音程の情報が消えてるから余計わかりにくい」。総譜を見せると「大変だなという感じ」。旋律は「3声が濁らない」「意味の塊に形を当てる」を優先し、歌う側の負担（4度以上の跳躍が432か所中83）を勘定していなかった。VOICEVOX は跳躍しても外さないので表に出なかった

## メイキング記事と概要欄

- 西尾「カノンである音楽的な理由を僕はよくわかってない」を受けて、メイキング記事の前半を音楽の説明にした。説明の芯は「ずらす長さを和音進行の1周に揃える」。27.2秒で3声が別々の句の「空」を同時に唱えて Em になる瞬間を記事の顔にした（狙ったのでなく規則を守った結果。プログラムで列挙して探した）
- 画面を共通のピアノロールに作り直したことで、この説明が目で確かめられるようになった
- 英語表記は「Heart Sutra Canon」（原曲名と同じ「〜の Canon」の形。The Canon of the Heart Sutra は「経典の正典」とも読めるので採らなかった）。西尾の提案で動画にも併記
- サムネイルは同じ「色即是空」を3声の色で1段ずつずらして置き、カノンの形を一目で見せた
