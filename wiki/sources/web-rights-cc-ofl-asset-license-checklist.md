# 素材の利用条件の確かめ方（CC・SIL OFL・素材サイト）

## 何の文献か

ライセンスの正文（CC BY 4.0・BY-NC 4.0、SIL OFL 1.1）、CC の公式の解説（帰属の推奨、AI 学習の指針）、日本の無料素材サイト 2 つの規約。公開の「確かめ方のチェックリスト」そのものは見つからなかったので、条文に出てくる条件を項目に起こした（項目の立て方は担当の整理）。Pixabay・Unsplash の規約は、それぞれ Cloudflare と Anubis（JavaScript の確認）で止まり読めなかった。フォント・BGM の個別の素材サイトの比較は means-sound-font の担当。

## 書いてあること

### Creative Commons

- CC BY 4.0 の 3 条 (a)(1): 共有するとき（改変したものを含む）、ライセンサーが付けていれば (i) 作者の表示（指定された方法で、筆名も可）、(ii) 著作権表示、(iii) このライセンスへの言及、(iv) 無保証の表示への言及、(v) 素材への URI・リンク（合理的に可能な範囲）を残す。さらに「**改変したならそう示し**、前の改変の表示も残す」「このライセンスの下にあることを示し、ライセンスの本文か URI を含める」
- 3 条 (a)(2): 媒体・手段・文脈に応じた合理的な方法でよい。例えば必要な情報を載せたページへのリンク
- 2 条 (b): 同一性保持権などの人格権、パブリシティ・プライバシー、特許・商標はライセンスされない（ライセンサーは行使しないよう努める）
- BY-NC の定義:「NonCommercial means not primarily intended for or directed towards commercial advantage or monetary compensation」
- 帰属の推奨（CC wiki）: **TASL**（Title・Author・Source・License）。音楽を音声・動画に入れるときは、動画の中と説明欄で帰属できる。「Caution: Licenses with "ND" do not allow for adaptations. **Your use of CC-licensed music is often an adaptation!** …if you are using a song as background music in a podcast or in a video, it is considered an adaptation of the song」
- AI 学習の指針（2025）: CC ライセンスは著作権の許諾なので、権利制限が効く場面には及ばない。「**日本のような一部の法域では、学習に必要な複製は権利制限に当たり許諾が要らない**」。保守的に従うなら、BY は学習データの出所へのリンク、SA は出力とモデルを同じライセンスに、NC は学習と配布を非商用に、ND は学習に使わない、と書いている

### SIL Open Font License 1.1

- 許諾: フォントを使用・研究・複製・結合・埋め込み・改変・再配布・販売してよい、ただし条件付き
- 条件 1: フォント（その部品も）を**単体で販売してはならない**
- 条件 2: ソフトウェアと同梱・再配布・販売するときは、著作権表示とライセンスを各コピーに含める
- 条件 3: 改変版に予約フォント名（Reserved Font Name）を使わない（書面の許可がない限り）
- 条件 4: 作者・権利者の名前を改変版の宣伝に使わない
- 条件 5:「フォントはこのライセンスの下でだけ配布する。**この要件は、フォントを使って作った文書には及ばない**（"does not apply to any document created using the Font Software"）」

### DOVA-SYNDROME（2026-09-15 に OpenTracks へ改名と告知。URL は dova-s.jp のまま）

- 前提: 使用料は請求しない。「**著作権表示・提供等の表示は不要**」。作曲者が別に条件を設けていればそちらが優先（ただし使用料・表示・禁止事項はサイトのライセンスが優先）
- 範囲: 営利（商用）・非営利、個人・法人を問わず、**背景音楽として**使える。YouTube・TikTok・プレゼンテーション動画・CM・ゲームなどの例。「作業用 BGM」のように音源が主のコンテンツは範囲外。カバー・アレンジ・歌を乗せる「音楽作品」は UGC での無償配信に限って可
- 加工: 形式変換、エフェクト、切り出し・ループは可。「元の音源から乖離、あるいは評価を著しく損なうと判断される加工は不可」
- 禁止事項（抜粋）: 「**音源を政治・宗教その他のイデオロギーに関する制作物・コンテンツで使用すること**」、音源の配布・販売、「**音源を AI のトレーニングに使用すること**」、音源や音源を使った作品を JASRAC 等に登録すること、「音楽として UGC サービスその他のプラットフォームにおける**フィンガープリント（YouTube においては Content ID…）に登録すること**」
- 作曲者は、権利をすべて持ち、管理団体と契約していない（カバーなら原曲が PD）ことを保証して公開している。違反すると権利者から申し立てがありうる

### いらすとや

- 「規約の範囲内であれば、個人、法人、商用、非商用問わず無料」
- 断る用途: 公序良俗に反する、素材のイメージを損なう攻撃的・差別的・性的・過激な利用、反社会的勢力・違法行為、**素材を主体としたコンテンツ・商品の再配布・販売**、その他作者が不適切と判断した場合
- 有償: 「**素材を 21 点以上使った商用デザイン**（重複はまとめて 1 点）」、高解像度データ。Canva の中だけで完成させるなら 20 点の制限なし
- 著作権は放棄していない。編集・加工は自由だが権利は移らない。「全ての規約は予告無く改変する場合があります」

## この wiki への含意

- **般若心経の動画（宗教の題材）に DOVA の BGM は使えない**（禁止事項 2「政治・宗教その他のイデオロギーに関する制作物」）。般若心経を宗教の制作物と見るかは解釈だが、文言に当たる。同じく AivisSpeech の声（ACML 1.0）は「政治・宗教的主張」を禁じる（[[exp-qualia-video]]）。[[exp-sutra-songs-on-music]] の VOICEVOX の声も、キャラクターごとの規約を確かめる対象。sutra 系は素材の「用途の禁止」が先に効く
- **CC の ND の曲は動画の BGM に使えない**（CC 自身が BGM を翻案と書く）。IMSLP の録音で ND が混ざる（[[web-rights-public-domain-music-imslp-musopen]]）のはここで落ちる
- **フォント**: OFL のフォント（Noto Serif CJK JP Black、[[exp-sutra-songs-on-music]]）で作った動画は、OFL の配布条件の外。フォントのファイルを repo や配布物に入れるときだけ OFL の本文を添える
- **DOVA の BGM を使った作品は Content ID に登録できない**。西尾が自分の動画を Content ID で守る段階になったら、BGM は自作か、登録を禁じない素材にする
- 経験の「素材ごとの出典・確信度・権利者を MANIFEST に書く」（[[exp-nishio-showreel]]）に、この表の 12 項目と「規約を読んだ日・版」の欄を足すと、公開の前の確認がそのまま記録になる（担当の提案）
- promo では「商用」「表示」が、talk では「用途の禁止」「表示」が、embed（会場で流す）では「上映・上演が範囲に入るか」が先に効く。DOVA は店舗・イベント・プレゼンテーション動画を例に挙げているので embed でも使える側

## Open Questions

- 「商用」の線: 収益化していない YouTube の作品紹介は商用か。CC の NC の定義（"primarily intended for… commercial advantage"）と、いらすとやの「商用デザイン」は同じ線ではない
- Pixabay・Unsplash など海外の素材サイトの現行の規約（AI 学習の禁止、生成物の扱い）は読めなかった
- VOICEVOX の各キャラクターの規約、GeneralUser GS（SoundFont）の条件は、この担当では読んでいない（means-voice・means-sound-font の範囲）
- 規約の「予告なく変更」に対して、ダウンロード時の版を残す方法（手元に HTML を保存するか。Internet Archive の Save Page Now に保存を頼むのは外に出る行為なので、西尾の運用として決めること）
