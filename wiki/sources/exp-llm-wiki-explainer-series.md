# LLM Wiki 1 分解説動画シリーズ（構想のみ）

## 何を作ろうとしたか

- 起点は西尾「1分間解説動画シリーズとしてLLM Wikiの解説をすることを考えている」（2026-10-02）
- 1 本 60 秒、字幕のみ、120BPM の BGM、全 7 本のシリーズの案（構成検討.md §3・§4）
- **状態: 構想段階。動画は作っていない**（構成検討.md 冒頭）。想定した制作 dir `~/llm-wiki-explainer-video/` は 2026-11-09 時点で存在しない。2026-10-06 以後に続きの commit も LOG の記録もない（`git log -- llm-wiki-explainer-series` は c0959b2 の 1 件）

## 決まったこと（西尾の決定）

- **宛先 = 一般の知的生産層。Claude Code はまだ使っていないかもしれない人**（構成検討.md §1、西尾決定）
- そこから導いた方針（同 §1。AI が整理した文）:
  - 専門用語（Ingest / file back / ハーネス）は出さず、「放り込む」「書き戻す」のような普通の言葉で言い切る
  - 「で、何を使えばできるの？」に必ず答える。ぼかすと真似できずに終わる。1 本目は道具名を小さく見せ、最終回で始め方を正面から扱う。これは grasp-nishio の決まり「発信物はモデル名を明示」と同じ向き

## 作り方の想定（流用する型と制約）

構成検討.md §2 に書かれた前提。実際には作っていないので、ここは「使うつもりだった」型。

- 描画: canvas に `renderFrame(f)` で描き、puppeteer で撮り、ffmpeg でつなぐ。BGM は numpy で合成。`~/nishio-showreel` 以来の型（[[exp-nishio-showreel]]、直近例 [[exp-democracy-river-video]]、[[exp-gyazo-resumption-video]]、`~/words-as-public-goods-video`）
- 配信面の制約（llm-wiki `analyses/講演の短尺動画化では制約は配信面から来る-20260930`）: X は無音自動再生なので字幕だけで通じる／最初のコマがサムネイルになるので焼き込む／YouTube のチャプターは全部 10 秒以上／英語ナレーションを入れると尺が延びる
- 画面: 本物の wiki 森を映すと private wiki や他人の project 名が映り込む。**図形と文字だけで描けばこの問題は起きない**（words-as-public-goods と同じ方針）

## シリーズ構成の案

1 本 1 概念にして、「冒頭で問い → 最後に回収」の形に乗せる。ネタ元は llm-wiki の概念ページ（2026-10-02 時点で concepts/ に 183 件）。多くが「〜は〜だ」の一行の主張になっているので、1 本の芯にしやすい、という見立て（構成検討.md §3）。

7 本の題（案）: 整理しなくていいメモ帳／要約するのでなく、つなぐ／聞いた答えが残る／書いてから整理する／AI の答えは仮説／育ったら株分け／何から始めるか。

1 本目の 60 秒台本案は「秒・字幕・絵」の 3 列の表で書いた（同 §4）。骨格だけ写すと:

| 秒 | 役割 |
|---|---|
| 0–0.7 | サムネイル用の大きな文字（最初のコマ） |
| 0–13 | 問題提起（メモが溜まる、整理しようとすると手が止まる） |
| 13–43 | 仕組みを 3 段（入れる → つながる → 聞くと答える） |
| 43–52 | 実例と数字（「40以上」の wiki。数字はレジストリで確認できるものだけ） |
| 52–60 | 締めと次回予告 |

## 詰まったこと・落とし穴

- **台本案の芯が、西尾自身の先行の結論と逆だった。** 13–21 秒に「放り込むだけ。整理は AI がやる」を置いたが、2026-09-09 の LT の結論は「目的の明確でないWikiはうまくいきにくい」「まとめてと頼むと詳細が消える」だった（構成検討.md §4「この台本案の問題」、LOG 2026-10-06）。台本を出したあとの file back の重複チェックで気づいた
- LOG に残した教訓（AI の側の反省、原文）: 「**同じ宛先への説明を自分が以前に作っていないか、台本を書く前に読む。**」
- 直し方の案（未実施）: 1 本目の芯を「目的を一つ決めて、AI に育てさせる」へ寄せる。シリーズに「目的が先、Wiki は後」の回を足す。LT から流用できる素材（サーベイが 3 週間で飽和した話、実験で得た知識はネットに書いていない、人間は LLM Wiki を書かない・読むことも期待しない）
