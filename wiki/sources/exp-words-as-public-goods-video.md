# Words as Public Goods の X 用縦長動画

## 何を作ったか

- 元: 西尾の LT「Words as Public Goods / 公共財としての言葉」（2024-01、Plurality Tokyo のイベント）。スライドは CC-0
- 動画: 50 秒・1080×1350（4:5 の縦長）・30fps、音声付き約 8MB（`out/words_as_public_goods_x.mp4`）
- 写真は使わず図形と文字だけ。アイコンは西尾本人のもの
- 投稿されたかは README からは分からない（「投稿前に出た問題（未決）」の節がある）
- 作り方の共通部分は [[exp-html-capture-pipeline]]

## 起点（西尾の依頼、そのまま）

「これのX投稿用の動画を作りたい、みんなが最後まで見てしまうようなやつ」（2026-09-30）

## 構成の設計（README の「設計（最後まで見てもらうために）」）

設計意図として書かれたもの。効果は測っていない。

- **冒頭の問いを最後に回収する**: 1 コマ目から「納得／これ、英語で言えますか？」。答え「次は、nattoku かもしれない」は 42 秒で出す
- **無音でも伝わる**: すべて字幕で読める。日本語を大きく、英語を小さく併記（二言語で並べること自体がトークの主張の実演になる、という狙い）
- **場面を 2〜6 秒ごとに切り替える**: 120BPM、切り替えは小節頭、下端に進行バー
- **ループしやすい終わり方**: 最後は背景にフェードし、頭の「納得」に戻る
- **写真を使わない**: 第三者の権利確認が要らない
- 流れ: 「納得」→ agreement / understanding / satisfaction に取り消し線 → 「英語には、ここに穴がある」→ すべての言語は穴だらけ（ロシア語の青の例）→ 2 つの円を重ねると穴がふさがる → 言葉は公共財 → 言葉を輸出しよう（tsunami / emoji / karaoke / kaizen）→ 次は nattoku → エンドカード

## 作り方

- 縦長 4:5 にしたので、`capture.mjs` の viewport を 1080×1350、fps を 30 に変えた。画像（アイコン）を描くので、showreel 1 分版の HTTP サーバー入りの撮り方を流用
- `reel.html` の `win(t, a, b)` で「区間に入ったら下からスライド、出るときフェード」を共通化
- BGM は「X は無音自動再生が多いので控えめなアンビエント」（`src/audio.py` 冒頭のコメント）。pluck と pad 中心
- 撮影は約 1 分（README）

## 事実の扱い

README の「事実の出典」に、トークの Cosense ページと、**動画で新たに足したもの（トークにない）**を分けて書いた。

- 「日本語話者は世界の約 1.5%」: 人口の割り算。トークでは「マイノリティ」と言っただけ
- tsunami などが英語の辞書に載っていること
- 「次は nattoku かもしれない」は動画の締めとして書いた提案で、トークにはない
- satisfaction はトーク後の補足で追加された候補

## 詰まったこと・西尾のフィードバック

投稿文案を見た西尾の評（そのまま）:「これ日本人向けには「そうか？」という気持ちになるなぁ、日本人向けメッセージとGlen向けメッセージが混ざってるんだわ」（2026-09-30）

README に書かれた分析（AI が書いたもの）:

- 今の構成（納得の穴 → 特殊な社会の特殊な語彙 → nattoku を輸出）は、ほぼ英語話者向けの論証。日本人には「言えないのは知ってる、それで？」になり、日本特殊論にも聞こえかねない
- 日本人向けの材料はトークにあるのに動画で使っていない（英語で分からなかった詩が中国語訳で分かった話、など）
- 「翻訳を待たなくていい」は 2024-01 時点の呼びかけで、その後の状況では古い
- 提案: 2 本に分ける。英語版は今の構成で英語を主・日本語を従に入れ替える。日本語版は別の入口から入る
- 日本語版の締めは (a)「日本語のままでいいから公開しよう」と (b)「他言語の訳と見比べると理解が深まる」で未決

その後の西尾の発言:

- 「"Listen for the words your language is missing"って上から目線な気がする」（2026-09-30。英語の文言案に対して）
- 「まずは英子版から考えよう」（同日。「英語版」の打ち間違いと読める）

## 教訓として言えそうなこと

- 二言語を併記すると、宛先も二つになる。どちらに向けた論証なのかを先に決めないと、片方の視聴者には刺さらない（西尾の指摘からの読み取り）
- 宛先の問題は、動画を作った後、投稿文を見せた段階で出た。構成を決める前に「誰に見せるか」を聞いていれば早く分かった可能性がある（推測）
