# Rosling 型の「data presentation」: Roslingifier の分析と、Rosling の五つのヒント

## 何の文献か

- **Roslingifier**: 時系列データから、Rosling 風の語り付き動くバブルチャートを半自動で作るシステムの論文。前半に、**話し手が動く可視化を使って生で語る発表**を観察して技法を分類した節がある。ここで主に使うのはその分類
  - 読んだのは Niklas Elmqvist のサイトにある PDF で、表紙は「ANONYMOUS AUTHOR(S)」、CHI '21 の投稿版。出版版は IEEE TVCG（IEEE VIS 2022 の発表一覧で確認）。投稿版と出版版で数値や記述が変わっている可能性がある
  - 観察の方法: 「話し手の声だけでなく姿が映っている」データの発表動画から、TED、ニュース・天気予報、Gapminder のような組織の動画を種に探し、データについて伝える・対話的か動く可視化がある・話し手の体と可視化が組み合わさっている、の三条件で 11 本を選んだ（Rosling が 6 本: ニュース番組でのホログラム風の表示 3 本、TED で舞台上から自分で操作した 3 本。ほかに Al Gore の映画 "An Inconvenient Truth" の CO2 のグラフ、Represent Us の政治動画、BBC の EU 国民投票と天気予報、CNBC の株式市場の解説）。著者二人が独立に符号化し、食い違いは話し合い、決まらなければ三人目が裁定した。「網羅でなく代表」を狙ったと書く
  - 後半の利用者調査はシステムの評価で、**比較条件の無い**評価（作り手 14 人が使って評価、視聴者 36 人が 1 本の動画を見て 7 段階で評価）
- **Rosling の五つのヒント**: Garr Reynolds（"Presentation Zen" の著者）のブログ記事（2010-07-11）で、Rosling 本人が Gapminder のソフトでバブルを見せるコツを語った動画を Reynolds が要約したもの。**Rosling の元の動画は見ていない**。Reynolds の要約による

## 書いてあること

### Roslingifier: 話し手が動く可視化を語る技法の分類（Table 1）

| 分類 | 技法 | 論文の説明（要約） |
|---|---|---|
| 身振り | Pointing | 手で一つの要素を示して聴衆の注意を向ける |
| | Tracking | 動いている要素を指しながら動き、変わるデータを説明し傾向を強調する |
| | Shaping | 手でデータの形を表し、広がり・範囲・境界を強調する |
| 視覚効果 | Labeling | 要素やまとまりに語や句で名前を付ける |
| | Spotlighting | 一時的に要素の見た目を変えて注意を引く |
| | Tracing | 動く要素の軌跡を描き、傾向を強調したり動きを比べたりする |
| | Accumulation | 要素を足していき、時間による変化を強調する |
| 再生操作 | Pause | ある時点の出来事に注意を向けるため、短い間アニメーションを止める |
| | Slowdown | 短い期間の細かい出来事の連なりを説明するため遅くする |
| | Speedup | 長い期間の傾向を説明するため、または何も起きない区間を飛ばすため速くする |
| | Rewind | 数コマ戻って、変化を繰り返し見せる、または別のことを伝える |
| | Replay | アニメーション全体を繰り返し、発表をまとめる |

- 序論で、Rosling の TED 2006 の講演は 200 近い国の軌跡が大画面で跳ね回る混乱した素材を、**話し続ける語り**、**手（後には指し棒）で重要な出来事を示すこと**、**一時停止と巻き戻しで時間を分岐させること**の三つで、筋の通った話にまとめたと書く。Rosling の語りは音の高さと速さ、すぐに使う「リプレイ」から、スポーツの実況にたとえられてきた、と書く
- 再生操作の使われ方について次のように書く
  - 一時停止は主に、ある出来事（世界大戦、スペイン風邪など）の傾向や理由を説明するのに使われる。天気予報では地図を止めてその週の異常な天気を強調した
  - 減速は一時停止の代わりに、出来事や理由を説明しながら使われることがある。加速は一時停止や減速の後に続き、重要でない区間を飛ばす
  - Rosling は全体の傾向を説明した後、**アニメーション全体をもう一度再生する**ことが多い。発表の最後にまとめとして、または途中で「次の段に移る前に聴衆に話を消化する時間を与える」ために使う、と書く
  - Rosling は一時停止・再生し直し・巻き戻しを速さを変えて組み合わせ、同じ期間について複数の見方を見せる。論文はこれを「temporal branching」と呼ぶ
- この形を **data presentation**（対面の話し手が、データの可視化を主な推進力として使うもの）と呼び、data video（字幕や姿の無い声で語るもの）とは別の種類だと書く。Rosling 自身が声だけで出る動画は data video の側に分類している
- 利用者調査（比較条件なし）: 視聴者 36 人（Prolific、平均 29.4 歳、平均 19.3 分）は 1 本の生成動画に 7 段階で、減速 6.71、語り 6.65、巻き戻し 6.09、理解しやすさ 5.79 などと答えた。作り手は巻き戻しをあまり使わず（「年が進むのに同じ期間に戻るのは少し混乱した」）、視聴者は減速と巻き戻しを作り手より高く評価した。著者は「視聴者は、語りを見直し消化する時間をくれる技法を好む」と解釈している。作り手の一人は「アニメーションの最後に全体の傾向をまとめる静止したコマが欲しい」と書いた

### Rosling の「バブルを見せる五つのヒント」（Reynolds の要約）

1. 全画面にして表示を最大にする
2. **先に**縦軸と横軸、バブルの大きさと色の意味を説明する
3. 特に注目してほしいいくつかのバブルにマウスを重ねる
4. 最適な速さに設定し、**アニメーションを始める時を聴衆に告げる**
5. **動いている最中に**、動きの意味を説明する

Reynolds は日本の高齢化と出生率の例で、Rosling が「まずグラフを説明し、何を見ればよいかを示し、それから意味を説明する」と書き、最良の発表は定量的な表示とその議論を、語り・関係する画像・インタビュー・物語や例と釣り合わせて混ぜる、と書く。

## この wiki への含意

### embed の Open Question「ループさせるか、止めて話すか」への答え

- この二つの文献が示す Rosling 型は、**ループでも、黙って流すのでもなく、話し手が時間を握って語る**形。止める（Pause）、遅くする（Slowdown）、飛ばす（Speedup）、戻る（Rewind）、最後にもう一度通す（Replay）を、話の区切りに合わせて使う。論文の観察でも、止めるのは「理由を説明するとき」で、全体をもう一度流すのは「消化する時間を与えるとき」だった
- 五つのヒントを embed の手順に置き換えると: **流す前に**「何を見ればよいか」（軸・色・注目する点）を話し、**始める時を告げて**流し、**動いている最中は動きの意味だけを語る**。動画の側に録音した語りがあると、4 と 5 の「話し手が告げて語る」とぶつかる。Rosling 型に寄せるなら、embed の動画はナレーションを入れず、話し手の声で語る作りになる（推測）
- **Replay は「ループ」に近いが別物**: Rosling の再生し直しは、話し手が意図して一度だけもう一度流すもので、Keynote の Loop（次へ進むまで繰り返す。[[web-powerpoint-keynote-google-slides-video-playback]]）とは違う。ループが「話し手が他のことを話している間の背景」になるなら、Sanderson のいう「ナレーションと同じ点を伝える動き」（[[web-3blue1brown-explainer-advice]]）から外れやすい（推測）
- これらは観察と、比較条件の無い評価から来ている。「Rosling 型の方がループより伝わる」は示されていない

### 経験との照合

- 般若心経の同期解説（[[exp-sutra-sync-subtitles]]）は 45 秒・ナレーションなし・3 回反復で、**作り手が「反復」を動画の中に焼き込んでいる**。Rosling 型に照らすと、発表で使うなら「1 回目は話し手が先に見方（読み・サンスクリット・直訳のどれが光るか）を説明してから流し、2 回目以降は話し手が黙って音を聞かせる」という使い方が考えられる。動画の側にナレーションが無いことは、話し手が先に見方を話す形と相性が良い。ただし唱える音そのものが中身なので、流している最中に話し手が語ると音とぶつかる。Rosling の「動いている最中に意味を語る」は、音が中身の題材にはそのまま使えない（推測。試していない）
- 同じ同期解説で、長文の般若心経では「いま実際に読んでいる位置が分からない」となり、発声中の一語句だけを光らせた。Roslingifier の Spotlighting（一時的に要素の見た目を変えて注意を引く）に当たる。経験では動画の中の強調で解決したが、発表では話し手の指し示し（Pointing・Tracking）で補う道もある
- クオリアさんの A/B/C 比較（[[exp-qualia-video]]）は 4 秒の三案を人が見比べたもので、発表で見せるなら Rosling 型の「先に何を見るかを告げてから流す」がそのまま使える（例:「右上の人物だけを見てください」）。推測

### talk・promo への含意

- talk（録画の解説動画）は、論文の分類では data video の側。話し手の体が無いので、身振りの技法は画面の中の視覚効果（ラベル・スポットライト・軌跡）で代わりにやる。Roslingifier はまさにそれを自動化しようとしたシステムで、語りは字幕として出す
- promo には関係が薄い

## Open Questions

- 観察は 11 本（うち Rosling 6 本）で、「代表」を狙った選び方。技法の頻度や効果は測っていない。利用者調査には比較条件が無く、7 段階の評価は好みの指標であって理解の測定ではない
- 読んだのは CHI '21 の匿名投稿版。出版版（IEEE TVCG）で分類や数値が変わっているかは確かめていない
- Rosling の五つのヒントは Reynolds の要約で、Rosling の元の動画は見ていない
- Rosling は Gapminder（Trendalyzer）のソフトを**生で操作**していた。録画した動画ファイルを発表のスライドに埋め込む場合、操作できるのは再生・一時停止・コマ送り程度で、速さを変える・特定の要素を光らせることは事前に作り込むしかない。生で操作できる道具（Motion Canvas の presentation mode など。[[web-motion-canvas-presentation-mode]]）と、録画した動画のどちらが embed に合うかは、文献からは決まらない
- 動画に音（BGM・TTS・唱える声）があるとき、話し手の声とどう共存させるかは、この二つの文献では扱われていない（Rosling の素材は無音のグラフ）
