# 表現としての音: Chion の added value・synchresis と Murch の「音を伸ばす」

## 書いてあること

### Chion の用語（FilmSound.org の編集抜粋）

- **audiovisual contract（視聴覚の契約）**: 音と映像の関係は自然なものではなく、観客がスピーカーの音とスクリーンの絵を同じ世界のものと見なすことに同意する一種の象徴的な約束。その結果「**音を聞くと同じものを見ていない。見ると同じものを聞いていない**」
- **added value（付加価値）**: 「音が映像を豊かにする表現的・情報的な価値で、その意味が映像そのものから『自然に』出てきたという確かな印象（即時の、または記憶の中の）を生むもの」。付加価値のせいで「音は要らない、音は映像の意味を重ねているだけだ」という**誤った印象**が生まれるが、実際には音がその意味を、単独で、あるいは映像とのずれによって作っている。例としてテレビの航空ショーの中継（1984）で、司会が映像に付けた「冗長な」コメントが、実は見え方を導き構造づけていた、と書く
- **synchresis（シンクレシス）**: synchronism（同期）と synthesis（合成）を合わせた造語。「見えるものと聞こえるものが**まったく同時に**起きたときの、心の中での融合」。一つの顔に何十もの声が許され、金槌のショットには何百もの音のどれでも合う。斧で薪を割る音を野球のバットの打撃に正確に同期させると、制作者の誤りでなく特に力強い打撃として「読まれる」。音を予期しているとき（人が歩くなど）synchresis は止められず、足音にほぼどんな音でも使える
- **temporalization（時間化）**: 付加価値の最も重要な効果の一つで、音が映像の時間の知覚に影響する。三つの面——**時間の活性化**（静止したショットが滴る水や足音で時間の流れに入る。音の持続の仕方で活性化の度合いが変わり、なめらかな持続音より不規則なトレモロの方が「活かす」）、**線形化**（現実音を付けると、ショットが線的に続く時間として感じられる）、**ベクトル化**（音は時間の向きを持つので、ショットを未来・目標へ向かわせ、切迫と期待を生む）
- **empathetic / anempathetic sound**: 場面の気分に合わせる音（共感的）と、場面に無関心な音（非共感的。登場人物が死んでもラジオが陽気な曲を流し続ける、シャワーが流れ続ける）。後者は「感情を凍らせるのでなく、宇宙的な背景の上で強める」と書く
- **vococentrism（声中心）**: 視聴覚メディアでは声が他のすべての音に優先し、声の存在が知覚の階層を作る。ミックスでは声を人工的に持ち上げる必要がある（The Voice in Cinema pp.5–6 の抜粋）
- **rendering（表現）**: 現実に聞こえる音の忠実な再現ではなく、状況の感覚・効果を伝える音。熊の重さ・力は、映像だけでなく洞窟のような足音（フォーリーで作った）で伝わる。転倒の音はしばしば大きな衝撃音で、重さ・暴力・痛みを伝える
- **acousmêtre**: 声だけが聞こえ姿が見えない人物。音源の正体の明示を最後まで遅らせることで力を持つ（『オズの魔法使い』の魔法使い）。姿が見えると力を失う

### Murch "Stretching Sound to Help the Mind See"（2000）

- 映画の音は「それ自体として評価されることは稀で、主に映像を強めるものとして働く。音がもたらす美点は、観客には主に映像の言葉で知覚され評価される。**音が良いほど、映像が良い**」
- 音と映像の**再結合**（reassociation）は創造的な音の使い方の土台。便宜のため（雪を踏む音はコーンスターチを踏んだ方が雪らしく録れる）、必要のため（割れる窓は砂糖の板）、倫理のため（人の頭を潰すよりスイカを潰す方がよい）に行われ、観客は「ある限度の中で」それを真実として受け入れる
- 「この再結合は、可能な所では音と映像の関係を**伸ばす**べきだ。画面にあるものと観客の心に灯るものの間に、意図的で実りある緊張を作るべきだ」。現代の映画は対象を「全部そこにある」ように見せるので、絵画・音楽・文学・ラジオドラマ・無声映画が持つ「感覚の不完全さ」による想像の余地を失いやすい。そこで「何を除くかを慎重に選び、映像と少し食い違うように聞こえる音を足し戻すと、観客の心がなだれ込む**知覚の空白**を開ける」
- 両眼の像の差から脳が奥行きを作るのと同じように、音と映像の隔たりを心が融合すると「次元」が生まれ、それは映像から来たように投影される。「私たちは映画を見て聞くのではなく、聞き見る（hear/see）」
- 隔たりの段階の例: 明かりを点ける映像に単純なカチッという音——ほぼ瞬時に融合し、平板。扉が閉まる映像に正しい「バタン」——扉の材質と空間だけでなく閉めた人の感情も示せる（『ゴッドファーザー』の最後の扉）。**画面の何とも直接結び付かない音**——解決にもっと時間がかかり、より高い次元で働く（『ゴッドファーザー』の殺人の直前の高架鉄道の金属的な悲鳴は、マイケルの心の状態の手がかりになり、銃声でその隔たりが一気に閉じる）。『地獄の黙示録』冒頭のホテルの部屋に満ちるジャングルの音は、画面にも近所にも音源が無く、ウィラードの心の中だと想像するしかない
- 「危険は、映像と音をつなぐ概念の糸を伸ばしすぎて、次元が崩れることだ。最大の次元の瞬間は、常に最大の緊張の瞬間でもある」
- 音の欠如も緊張を作る: 『ゴッドファーザー PART III』の最後、叫ぶ顔に音が無い（俳優は実際に叫んでいたが編集で消した）

### Murch: 音を消して組む（インタビュー 2020-02-10）

- 「場面を組むとき、私は音を一切参照せずに組む」。撮影時の台詞の音は完成した音ではなく、気を散らすことがある。音を消して組み、何度か組み直してから音を入れると、偶然の並置にうれしい驚きがある、と言う。逆に Dede Allen は台詞だけでラジオのように場面を切ってから絵を付けた、と紹介し、「いろいろなやり方がある」と言う

## この wiki への含意

- **synchresis は「拍に合わせる」の理論的な名前**: 西尾の HTML の描画は映像と音を同じ時刻表に乗せ、場面の切り替えを 120BPM の小節頭に置き、kick・clap・impact・whoosh を時刻指定で足した（[[exp-html-capture-pipeline]]）。Chion の synchresis によれば、同時に起きた音と映像は、音が現実の音源と違っても一つの出来事として融合する。抽象図形と文字だけの promo に合成した打撃音が「効く」のは、この融合に乗っている（推測）
- **added value の誤った印象と「音を外した評価」**: Chion は、音が作った意味を観客は映像から来たと感じる、と書く。西尾の経験で「動きが大事な版は静止画で評価できない」「20 秒の音声つき動画を作ったら即決した」（[[exp-sutra-hype-editions]]）は、評価を音つきでやる理由になる。逆に、音なしで評価した画面は音の付加価値を含まない
- **temporalization と「完全静止」の talk**: クオリアさんの talk は完全静止を既定にした（[[exp-qualia-video]]）。Chion の「静止したショットも音で時間の流れに入る」に従えば、静止画面でもナレーションが時間を作っているので、画面が止まっていても「止まった」とは感じにくいはず（推測）。ナレーションのない embed（般若心経の同期解説、[[exp-sutra-sync-subtitles]]）では、唱えの音そのものが時間を作り、現在位置の光りがそれに同期する
- **vococentrism と embed の声の分担**: 声は他の音を従える。流しっぱなしの embed で、動画のナレーション（TTS）と会場の話し手の声が同時に鳴ると、声どうしが階層を争う。embed の Open Question「流しっぱなしで話し手と動画の声がどう分担するか」（[[embed]]）に、Chion の用語は答えないが、「二つの声は同時に置けない」という制約を名指す（推測）
- **ドロップ直前の無音・暗転と「音の欠如」**: アゲアゲ版の「ドロップ直前 1 拍は無音＋暗転」（[[exp-sutra-hype-editions]]）は、Murch の言う「欠如が作る緊張」と同じ技法。Murch の例は感情の山場の無音で、西尾の例はビルドの頂点の無音
- **伸ばしすぎると崩れる**: Murch の「音と映像の隔たりを伸ばすほど次元が増すが、伸ばしすぎると崩れる」は、promo の比喩的な音（抽象図形に打撃音）にも talk の説明の音（効果音で要点を指す）にも効く判断軸。ただし Moreno & Mayer は、学習目的の教材では効果音・BGM を足すと保持と転移が下がったと報告した（[[web-moreno-mayer-2000-coherence-sounds]]）。Murch と Chion は劇映画の表現の話で、学習の測定ではない。talk・embed で「音で意味を足す」なら、この食い違いを意識する

## Open Questions

- Chion の Audio-Vision 本文、Murch の Transom の講演 "Dense Clarity – Clear Density" は読めていない。Chion の用語は FilmSound.org の編集抜粋による
- added value・synchresis・temporalization はどれも理論家の観察と例示で、実験で効果を測ったものではない。音楽が映像の解釈を変えることを測った研究（映画音楽の心理学）は今回読んでいない
- 劇映画の音の考え（音を伸ばす、非共感的な音）が、説明が目的の talk・embed で理解を助けるのか妨げるのかは、Moreno & Mayer の結果（学習では余計な音が損）とぶつかる。どの条件で表現の音が理解を助けるかは分からない
- 西尾の動画は無音で自動再生される面（X）にも出る（[[exp-words-as-public-goods-video]]）。音の付加価値に頼った作りは、無音で見られると意味が抜け落ちる。promo では音ありと音なしの両方で通じる作りが要る（第 1 回の Meta の指針と同じ方向）
