# COEIROINK の利用規約

## 何の文献か

- 運営の公式規約とダウンロードページ。比較のため VOICEVOX のソフトウェア規約も読んだ。音質の評価は読んでいない（galleria でも比べていない）

## 書いてあること

### 版（2026-11-09 時点のダウンロードページ）

- 最新は **v2.13.0（2026-03-23）**。「GPU(DirectML)版を公開（2026-08-11）」。Windows・Mac・Linux、CPU・GPU(CUDA)・GPU(DirectML) の配布がある。v2.11.0（2025-04-21）で「windows版のソフトウェアポータブル化を廃止」

### 生成音声

- 「生成された音声を使用する際は**クレジット表記が必須**です。コンテンツ内、もしくは、コンテンツ概要欄のいずれかに『COEIROINK』と『合成音声名』が含まれるクレジットを記載してください（例『**COEIROINK:合成音声名**』）」。概要欄が無い音声作品は「クレジットの読み上げが必要」。別キャラクターにアテレコするなら、どのキャラクターにどの音声をあてたか分かるように
- 利用範囲は各キャラクターページ（MYCOEIROINK は音声提供者の規約）
- 「COEIROINKで生成された音声の著作権は、音声提供者が保有します」
- 生成音声を不特定の他者に二次利用（素材としての利用）を許す形で公開するのは禁止

### 共通の禁止事項

- 「人を批判・攻撃すること」「特定の政治的立場・宗教・思想への賛同または反対を呼びかけること」「刺激の強い表現をゾーニングなしで公開すること」「**機械学習用のデータとして使用すること**」など
- 詳細: 「主張の正当性にかかわらず、批判や攻撃を目的とした**活動**にはご利用いただけません。また、いかなる目的であっても、前述の活動をしている個人・法人・団体等と同じ名義ではご利用いただけません」。「攻撃」には犯罪・戦争・暴行・誹謗中傷・揶揄などのほか「アンチ活動」を含む。フィクションの戦闘・残酷な描写は制限しない（ヘイトスピーチは避ける）

### ソフトウェアとモデル

- ソフトウェアは商用・非商用とも可。ただし音声ライブラリの規約で商用が禁じられていればその音声は商用不可
- 「COEIROINKが提供する学習済み音声合成モデルを元に、別の音声合成モデルを作成すること。転移学習」は禁止。**例外**として「MYCOEIROINK作成手順に従い、COEIROINKから提供されたベースモデル用の学習済み音声合成モデルを用いてMYCOEIROINKを作成することは、例外的に許可」（2025-09-29 に補足追加）
- 提供モデル・MYCOEIROINK を COEIROINK エンジン以外で動かすことは禁止。ただし「COEIROINK起動時のローカルAPIを利用して、別のソフトウェアと組み合わせることは許可」（VOICEVOX のプラグインエンジンも可）
- 2023-09-22 の更新で、COEIROINK 上で動かしてよい音声ライブラリは「全て音声ライブラリ側の規約でクレジット表記必須」と明記

### VOICEVOX との比較（規約の条文から）

| | COEIROINK | VOICEVOX（ソフトウェア規約） | AivisSpeech |
|---|---|---|---|
| クレジット | 必須（「COEIROINK:合成音声名」） | 必須（「VOICEVOX を利用したことがわかる」） | 本体は不要（ACML・ACML-NC・CC0 のモデルなら義務なし） |
| 批判への利用 | 批判・攻撃を目的とする活動は禁止、その活動の名義での利用も禁止 | 「製作者または第三者に不利益をもたらす行為」「公序良俗に反する行為」を禁止（キャラクター規約は別） | ACML 1.0 が実在の製品への批判・攻撃目的を禁止（[[exp-galleria-tts-and-singing]]） |
| 自分の声 | MYCOEIROINK の手順でだけ | ソフトウェア規約に記述なし | Style-Bert-VITS2 で学習 → AIVM（[[web-means-voice-style-bert-vits2]]） |

## この wiki への含意

- **「批判・攻撃を目的とした活動をしている名義では、いかなる目的でも使えない」は、他のエンジンより広い**。[[exp-qualia-video]] は ACML の禁止事項に合わせて「他の製品が古臭い」という言い方を避けた。COEIROINK の条文は個々の台本でなく**名義の活動全体**を見るので、政治・社会の議論を扱う発信（例: [[exp-democracy-river-video]] の題材）と同じ名義で使う前に、その活動が「批判や攻撃」に当たらないかの判断が要る。判断は西尾がすること
- 「機械学習用のデータとして使用すること」の禁止は、生成音声を自分の TTS の学習データ（[[exp-galleria-tts-and-singing]] の Irodori の参照の束のような使い方）に回せないことを意味する（条文からの推論）
- クレジットは三者三様で、エンジンを替えると概要欄の書き方が変わる。grasp-nishio の「動画ではモデル名を明示する」と合わせ、台本の manifest からクレジット文を自動で作るのが筋（推測）
- 型: talk・embed のナレーション。promo の短尺でも、概要欄があればクレジットは概要欄で足りる

## 着手の仕方（未検証。galleria で確かめる）

- **何が表現できるようになるか**: VOICEVOX・AivisSpeech と別系統の声の在庫（MYCOEIROINK の第三者の声を含む）。型は talk・embed
- **機械**: galleria Windows（CUDA 版か DirectML 版）。入れるもの: COEIROINK v2.13.0。費用 0、アカウントの要否はダウンロードページからは読めなかった。利用条件: クレジット必須、上の禁止事項
- **成熟度**: v2.13.0（2026-03-23）、DirectML 版 2026-08-11、規約更新 2026-10-21。更新は続いている
- **最小の手順**: ダウンロードページから Windows・GPU(CUDA) 版を取り、起動。ローカル API のポートと仕様はこの調査で読めていない（推測: エンジン起動後のローカル API を [[exp-qualia-video]] の `generate_http_tts_sample.ps1` と同じ要領で叩く。ポートは起動ログで確かめる）
- **動いたと言える確かめ方**: [[exp-qualia-video]] の比較用の共通原稿で WAV が出て、他エンジンと RMS を揃えた試聴用コピーを人が聴ける
- **所要の見込み（推測）**: 1〜2 時間（API の仕様を起動後の docs で確かめる時間を含む）

## Open Questions

- MYCOEIROINK の作り方（録音量・学習の場所・費用）は JavaScript で描画されるページで、読めなかった
- COEIROINK v2 のローカル API の仕様（ポート、VOICEVOX 互換か）を一次資料で確かめていない
- 「批判や攻撃を目的とした活動」に、政策への意見表明や他の製品との比較がどこまで含まれるかは、条文の例示からは決まらない
