# 既存曲を動画に使う範囲（JASRAC・NexTone の包括契約、原盤、替え歌）

## 何の文献か

日本の二つの音楽著作権管理事業者（JASRAC、NexTone）の利用者向けページと FAQ、ニコニコの音楽のガイドライン、YouTube のヘルプ、著作権法の条文（e-Gov）。いずれも公式の説明で、法律の助言ではない。JASRAC の「手続きの要否のフローチャート」は JavaScript の対話形式で、中身は読んでいない。

## 書いてあること

### 包括契約で済むもの（作詞・作曲の権利だけ）

- JASRAC:「JASRAC が利用許諾契約を締結している動画投稿サービスにつきまして、動画の投稿者は一定の範囲内でのご利用であれば、JASRAC 管理楽曲を含む動画を手続きなくアップロードすることができます。ただし、利用方法によっては、個別に手続きが必要となる場合があります」
- JASRAC の一覧（最終更新 2026-10-13）に載る主な動画サービス: **YouTube、ニコニコ動画、TikTok（TikTok LIVE を含む）、Instagram、Facebook、Threads**、Twitch、LINE ほか。**X（旧 Twitter）、LinkedIn は載っていない**（一覧の項目を全部見た）
- NexTone の一覧（ugc.pdf、2026-06-24 版）: YouTube、ニコニコ動画、TikTok、Instagram・Facebook（「投稿機能を用いる場合に限ります」）、Threads ほか。X は無い。「YouTube のエンベッド利用については投稿者による許諾手続きが必要になる場合がございます」
- **NexTone は個人の X 投稿に専用の申請を用意**している: PlayN（NexTone のオンラインシステム）で「X での利用許諾申請」をし、X のアカウント URL と開始日を書き、「個人で収益を得ずに行う楽曲利用」に印を付ける。第 5 営業日以内を目途に許諾番号。利用実績の報告も要る（マニュアル）
- ニコニコ:「JASRAC 管理楽曲・NexTone 管理楽曲の利用が許諾されているのは、楽曲の著作権に基づく利用のみです」

### 原盤（録音）は別

- JASRAC:「市販の CD やダウンロードした音源を利用する場合、著作権とは別に、著作隣接権（音源製作者やアーティストの権利）の許諾を得る必要があります。音源製作者（レコード会社等）へ直接お問い合わせください」（日本レコード協会の窓口一覧へリンク）
- NexTone FAQ:「CD 音源、配信音源等の第三者が作成した音源をご利用の場合、音源の製作者から許諾を得る必要があります」。自分で演奏・歌唱した動画は手続き不要
- ニコニコ: CD の音源は「許諾原盤」の範囲でだけ使える。許諾原盤は「許諾原盤検索システム」で確かめる。2026-11-09 時点で毎日数百〜1 万曲規模の追加が告知されていた（Warner Classics など）。**指定が解除されると、投稿時に問題が無くても削除されうる**と書いている

### 替え歌・編曲（同一性保持権・翻案権）

- JASRAC:「既存の楽曲を編曲したり、歌詞を翻訳または替え歌にする場合には、作詞者・作曲者の意向を確認する必要があります。当該楽曲の音楽出版社を通すなどして、事前にご確認ください」（主な音楽出版社の連絡先一覧へリンク）
- NexTone:「著作者の許可無く著作物に替え歌をつけたり、改ざん、変更を加えたりして著作物を利用することは、著作者人格権の侵害となります」
- YouTube（著作権 FAQ の「誤解」の節）:「パロディ、カバー曲、翻訳のように他人のコンテンツで新しいものを作るのも、たいていは著作権者の許可が要る」
- 著作権法 20 条（同一性保持権）:「著作者は、その著作物及びその題号の同一性を保持する権利を有し、その意に反してこれらの変更、切除その他の改変を受けないものとする」。27 条（翻訳権、翻案権等）:「著作者は、その著作物を翻訳し、編曲し、若しくは変形し、又は脚色し、映画化し、その他翻案する権利を専有する」

### 広告・宣伝の動画、法人

- JASRAC:「動画の内容が『特定の企業・団体や商品、サービスを宣伝するもの』に該当する場合、あらかじめ『広告目的複製』の手続きが必要」。音楽出版社が指定した金額（指し値）を払う。ライブ配信だけなら不要
- NexTone:「動画内に特定の企業や商品を宣伝する内容が含まれている場合、『広告目的複製』の利用申請を行ってください」
- JASRAC: 外国作品を含む動画を法人・学校・団体が上げる場合は「ビデオグラム録音」の手続き（指し値）
- JASRAC の「個人」は個人事業主を含む。アカウントを運営する者が企業・団体なら「個人以外」

### Content ID の申し立て

- JASRAC（2023-02-10）: YouTube が JASRAC 管理楽曲を検知すると、JASRAC の「著作権の申し立て」のお知らせが届くことがある。「著作権の侵害を主張するものではありませんので、その動画を削除したり、非公開にしていただく必要はありません」。それまで広告の無かった動画にも広告が付き、収益の一部が使用料として分配される。誤りと思えば Studio から異議申し立てを
- NexTone FAQ: 申し立ては「投稿者が著作者・アーティスト本人の場合でも行われます」。NexTone 管理作品を使っていないのに申し立てが来たら YouTube から異議申し立てを。YouTube には NexTone から連絡する機能が無いので、**異議の理由に返信用のメールアドレスを書く**。再生地域により他団体の申し立てが並ぶことがある
- YouTube（answer/2797454）: 異議申し立ての正当な理由は「必要な権利をすべて持っている」「フェアユースなどの例外」「誤認・誤り」。**クレジットを表示した、コピーを持っている、収益化しない、は理由にならない**。申立人は 30 日以内に応答（取り下げ／復活／削除要請＝著作権侵害の警告になりうる／放置で失効）。ブロックされた動画は「Escalate to Appeal」で直接再審査（申立人は 7 日）。乱用には罰

## この wiki への含意

- **残酷な般若心経のテーゼ**（[[exp-sutra-songs-on-music]]、2026-10-01 公開済み）の Open Question「替え歌が包括契約の範囲か」に、JASRAC・NexTone の公式の記述が答える: 包括契約は作詞作曲の利用を許すが、**替え歌は作詞者・作曲者の意向の確認が要る（JASRAC）／無許諾は著作者人格権の侵害（NexTone）**。Claude の当時の理解「替え歌は同一性保持権に関わり包括契約の範囲外で許諾が要る」と一致する。どちらの団体の管理曲か（J-WID・NexTone の検索で確かめる）、許諾を取ったかは、この wiki では確かめていない
- **エヴァ OP 様式の Polis**（[[exp-polis-magi-op]]）の README「原盤は使わず合成のカバー、YouTube は作曲の包括契約を前提」は、原盤を避けた点で JASRAC・NexTone の記述と合う。ただし歌詞を Polis の内容に変えたなら替え歌で、上と同じ確認が要る。また X に出すなら、両団体の UGC 一覧に X は無い（NexTone は個人・非収益の申請あり）
- [[exp-forest-misc-video-notes]] の「JASRAC の包括契約が効くのは作曲の権利だけで、原盤（録音）は別」は公式の記述と一致。正確には「作詞・作曲」で、編曲・替え歌・広告目的は別
- **promo（作品の宣伝）に既存曲を使うと「広告目的複製」に当たりうる**。西尾の作品・サービスの宣伝動画は「特定の…商品、サービスを宣伝するもの」に入るか。個人の研究や本の紹介が「商品」に当たるかは、ページの文言からは決まらない。promo の BGM は自作（numpy の合成、[[exp-polis-magi-op]]）か、利用条件の明確な素材（[[web-rights-cc-ofl-asset-license-checklist]]）が手間が少ない
- **X 用の動画**（[[exp-democracy-river-video]]）に既存曲を入れるのは、YouTube と同じ扱いではない
- embed: スライドに埋め込んで会場で流すのは「上演・演奏」で、UGC の包括契約とは別の利用。この担当では読んでいない

## Open Questions

- 「広告目的複製」の「宣伝」の線: 自分の研究・本・OSS の紹介動画は当たるか。JASRAC のフローチャート（対話形式）を西尾がブラウザで回すと答えが出る可能性がある
- 歌詞を全部差し替えた替え歌で、旋律だけを使う場合の手続きの窓口（音楽出版社か、作曲者個人か）
- 伴奏に使った「無料 MIDI」の打ち込みデータの権利（配布元の利用条件。MIDI データ自体が著作権法上の何に当たるかの公式の説明は見つからなかった）
- 会場での上映（embed）、学会発表の動画内の既存曲の扱い
- NexTone の X 向け申請が「個人・非収益」に限られる点で、西尾の発信が非収益に当たるか
